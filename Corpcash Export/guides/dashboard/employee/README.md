# Employee

The Employees module in CorpCash provides administrators with access to a centralized employee records interface for managing the organization's employee records and onboarding activities. The module enables Client Admin users to efficiently maintain the employee directory, monitor employee account status, review wallet balances, and manage employee-related information throughout the employee lifecycle.

From the Employees page, administrators can

* View and manage existing employee records
* Search for specific employees,
* Add new employees individually
* Upload employee records in bulk and
* Export employee information for further reference or reporting.

These capabilities help streamline employee onboarding and provide administrators with greater visibility and control over employee accounts.&#x20;

The page displays essential information associated with each employee in a structured tabular format. The available information includes&#x20;

1. **Employee ID**&#x20;
2. **Name**&#x20;
3. **Balance**
4. **Department**
5. **Grade**
6. **Created At**
7. **Updated At**
8. **Status**

This consolidated view enables administrators to quickly review employee information, assess account status, monitor wallet balances, and perform relevant administrative actions based on their assigned permissions.

The Status field provides visibility into the current state of an employee's account, while the Available Actions section provides access to applicable employee-level operations. The actions displayed may vary depending on the employee's status and the permissions assigned to the logged-in administrator.

## Employee Management Actions

#### Employee Directory

The Employee Directory occupies the main section of the Employees page and provides a tabular view of the employees registered within CorpCash. Each row represents an individual employee record and contains information that helps administrators identify and monitor the employee.

<figure><img src="../../../.gitbook/assets/image (126).png" alt=""><figcaption></figcaption></figure>

The directory displays the following information:

<figure><img src="../../../.gitbook/assets/image (128).png" alt=""><figcaption></figcaption></figure>

**ID:** The ID column displays the unique identifier assigned to the employee. This identifier can be used as a reference when locating or managing a specific employee record.

**Name:** The Name column displays the employee's name. The employee's registered email address is also displayed below the name, allowing administrators to distinguish between employees with similar names and verify the associated account.

**Balance:** The Balance column displays the current digital token or wallet balance associated with the employee. This provides administrators with a quick overview of the employee's available balance without requiring them to open the individual employee record.

**Department:** The Department column displays the organizational department associated with the employee, such as Marketing or Engineering. If department information has not been provided or is not available, the system may display a placeholder such as “—”.

**Grade:** The Grade column displays the organizational grade or level assigned to the employee, such as L1, L2, or L3. If no grade has been assigned, the field may display “—”.

**Created At:** The Created At column displays the date and time when the employee record was initially created in the CorpCash system. This information can be used to determine when the employee was onboarded or when the employee record was created.

**Updated At:** The Updated At column displays the date and time when the employee record was most recently updated. This allows administrators to identify when the employee information was last modified.

**Status:** The Status column displays the current status of the employee account. In the provided interface, the status is represented using visual indicators such as Pending, Active, and Inactive, allowing administrators to identify the current state of an employee account quickly.

**Actions:** The Actions column provides the available operation for the corresponding employee record. In the displayed interface, the View option is available. Clicking View allows the administrator to open and review additional information associated with the selected employee.

#### Search and Filter

<figure><img src="../../../.gitbook/assets/image (130).png" alt=""><figcaption></figcaption></figure>

The Employees page provides search and filtering capabilities that enable administrators to quickly locate specific employee records within the employee directory. These functionalities are particularly useful for organizations managing a large volume of employee records.

The Search field displays the placeholder “Search by name or email.” Administrators can enter an employee's name or registered email address to search for the corresponding employee record. As the search criteria are entered, the system dynamically filters the employee directory and displays records that match the specified criteria.

For example, entering “Rajesh Kumar” in the Search field enables the administrator to locate employee records associated with that name. Similarly, entering the employee's registered email address can be used to identify the corresponding employee record.

This functionality allows administrators to efficiently locate employee records without manually navigating through the complete employee directory.

<figure><img src="../../../.gitbook/assets/image (137).png" alt=""><figcaption></figcaption></figure>

The All-Status dropdown provides an additional filtering option. Administrators can use this filter to display employees according to their current account status. The available statuses shown in the interface include.

●     Pending

●     Active

●     Inactive

A Pending status indicates that the employee record is awaiting completion of the applicable onboarding, approval, or activation process.

An Active status indicates that the employee account is active and available for applicable platform operations.

An Inactive status indicates that the employee account is currently inactive and may not be available for normal employee operations.

Administrators can combine the search field with the status filter to further narrow the employee list. For example, an administrator can search for an employee by name and select Active from the status filter to display only matching active employee records.

### View Employee Details

The View option enables administrators to access the detailed profile of an individual employee. When an administrator selects View for a specific employee record, the system navigates to the Employee Details page, where all relevant information associated with the particular employee is presented in a consolidated view.

<figure><img src="../../../.gitbook/assets/image (134).png" alt=""><figcaption></figcaption></figure>

The Employee Details page provides administrators with comprehensive information about the selected employee, including their personal and organizational details and the wallets associated with the employee. This centralized view enables administrators to review employee information and wallet-related details efficiently.

Based on the administrator's assigned permissions and the employee's current account status, the page also provide access to employee-level actions, including Edit, Revoke Points, Resend Invite, and Back.
