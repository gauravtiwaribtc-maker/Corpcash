# Employee Onboarding

### Individual / Single Employee Onboarding

{% stepper %}
{% step %}
### Add Employee

To add a new employee, select **"Add Employee"** from the upper-right corner of the Employees page. The system opens the Employee Onboarding form, where the administrator can enter the required employee information.

<figure><img src="../../../.gitbook/assets/image (139).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Enter Employee Details

Administrators must provide the relevant employee details in the designated fields and complete the onboarding process as required. The available fields and information requirements are presented in the Employee Onboarding form, as illustrated in the image below.

<figure><img src="../../../.gitbook/assets/image (140).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Save and Finish

After entering all required details, review the information and complete the onboarding process according to the configured workflow.

The newly created employee record is subsequently displayed in the Employees table.

<figure><img src="../../../.gitbook/assets/image (141).png" alt=""><figcaption></figcaption></figure>

> The exact fields and validation requirements in the Add Employee form may vary based on the organization's CorpCash configuration.
{% endstep %}
{% endstepper %}

### Bulk Upload

The Bulk Upload option enables administrators to onboard or manage multiple employee records simultaneously. This functionality is particularly useful when an organization needs to add many employees without creating each employee record individually.

{% hint style="info" %}
If the user does not have the file format then they can download the template provided.
{% endhint %}

When user click on the **“Bulk upload”** a new window will popup as shown below in the image.

{% stepper %}
{% step %}
### Inititiation&#x20;

To perform a bulk upload, click **"Bulk Upload"** and provide the employee information in the format supported by the CorpCash platform.

<figure><img src="../../../.gitbook/assets/image (143).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Upload File&#x20;

To upload employee records in bulk, select the file from your computer or device but if you don't have the file format, click on **"Download Template"** to download the prescribed template file. Enter the required employee information in the downloaded file while. Once the employee records have been completed, upload the prepared file to the system and submit it for processing.

<figure><img src="../../../.gitbook/assets/image (142).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Finish and Close

After the file is uploaded, the system validates the submitted employee information against the defined data and format requirements before processing the records. Only records that successfully meet the applicable validation criteria are processed for employee creation or onboarding.

<figure><img src="../../../.gitbook/assets/image (144).png" alt=""><figcaption></figcaption></figure>

Note: The supported file format, mandatory fields, validation rules, maximum upload size, and processing behavior may vary depending on the CorpCash configuration.
{% endstep %}
{% endstepper %}

### Export

<figure><img src="../../../.gitbook/assets/image (145).png" alt=""><figcaption></figcaption></figure>

The Export option allows administrators to export employee records from the Employees page. This functionality can be used when employee information is required for reporting, reconciliation, administrative review, auditing, or record-keeping purposes.

Before exporting the records, administrators can use the available search and filtering options to narrow down the employee list. Once the required records are displayed, click Export to initiate the export process. The system generates the employee data according to the configured export functionality.

For example, an administrator can filter the employee directory to display only Active employees and then export the resulting records for further administrative use.

Best Practice: Apply and verify the required search and filter criteria before exporting employee information when a specific subset of records is required.
