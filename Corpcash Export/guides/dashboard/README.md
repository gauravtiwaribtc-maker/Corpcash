# Dashboard

## Accessing Corpcash

Once the user account has been successfully verified and approved by the Super Admin, an account verification email will be sent to the user's registered email address. The email will contain a user-specific URL that can be used to access the CorpCash platform.

The URL is generated based on the Domain provided by the user during the registration process. For example, if the registered domain is Delhi University, the user-specific URL will be:&#x20;

[DelhiUniversity.CorpCash.in](https://delhiuniversity.corpcash.in)

The user must select the URL provided in the verification email to access the CorpCash platform. Upon selecting the link, the user will be redirected to the CorpCash Login page, as shown in the image below.

The user can then enter their registered login credentials to access the platform and proceed with the functionalities available for their assigned role and permissions.

## Dashboard Panel

Upon successfully authenticating and logging in to the CorpCash application, the user is automatically redirected to the Dashboard, as shown in the image below.

The Dashboard serves as the primary landing page of the CorpCash platform and provides users with a centralized interface to access the products, services, and features available. It provides an overview of the available platform functionalities and enables users to navigate efficiently to the relevant modules and services.
