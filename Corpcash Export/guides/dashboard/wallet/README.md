# Wallet

#### Purpose

The primary purpose of the Admin Wallet module is to provide Client Administrators with a centralized interface to manage, allocate, and distribute digital tokens across the organization. Additionally, it offers comprehensive transaction-level visibility, enabling administrators to monitor distribution history, track wallet balances, and audit the real-time status of individual transactions. Consequently, the Admin Wallet serves two core functions:

#### Fund Management <a href="#i7nhqgerlyk4" id="i7nhqgerlyk4"></a>

Administrators can manage the funds available for organizational token distribution.

#### Fund Distribution and Monitoring <a href="#oocpf65c8d4z" id="oocpf65c8d4z"></a>

Administrators can distribute funds to employee wallets and subsequently monitor the transactions generated through these activities.

### Overview <a href="#befzf0vtacx8" id="befzf0vtacx8"></a>

The Admin Wallet allows authorized administrators to manage the organization's digital token balance and distribute tokens to employee wallets.

It serves as a centralized source of funds for operations such as adding funds, transferring funds, and revoking points. Additionally, it offers a consolidated view of transaction history, enabling administrators to track, filter, review, and export records.

An administrator can:

●     View the available Admin Wallet balance

●     Add funds to the wallet

●     Transfer funds to employee wallets

●     Revoke previously allocated points,

●     Search and filter wallet transactions

●     Export transaction records

●     Review of transaction details and statuses

## &#x20;Accessing the Admin Wallet

&#x20;Navigation to the Admin Wallet:

Corpcash > Wallets > Admin Wallet

&#x20;

1. Log in to the CorpCash platform using authorised URL and credentials.
2. From the left navigation menu, select Wallets.
3. Under the Wallets section, select Admin Wallet.
