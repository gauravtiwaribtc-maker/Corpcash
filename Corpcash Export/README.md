# Welcome

CorpCash is a multi-tenant enterprise benefits platform that enables organisations to digitally manage, distribute, and monitor employee benefits through a secure, controlled, Points-based wallet ecosystem.​

The platform brings employee benefits, rewards, digital wallets, gift cards, bill payments, vendor payments, settlements, reporting, and administrative controls into a single ecosystem.

Each organisation using CorpCash is provisioned with a dedicated client environment. Client Administrators use this environment to manage employees, vendors, wallets, transactions, settlements, reports, and other organisation-level configurations.

CorpCash uses Points as a closed-loop representation of benefit value.

**1 Point = ₹1 by default.​**

Points are not cryptocurrency and are not designed to be traded or transferred outside the CorpCash ecosystem. They represent benefit value that can be used by employees for supported services and payments within the platform.

This documentation is specifically designed for Client Administrators who are responsible for configuring and managing their organisation on the CorpCash platform. It provides step-by-step guidance for using the Client Admin Web Dashboard, including employee and vendor management, wallet configuration, Points distribution, transaction monitoring, vendor settlements, reports, audit activities, and Rewards Bridge access.
